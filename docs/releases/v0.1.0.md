# Angine v0.1.0

The first MIT licensed Angine MVP: a local dashboard for work reported by AI agents.

- Organize work as Projects → Missions → Tasks, including shared missions across agents.
- Follow progress, blockers, stale activity, and reporter connection health.
- Browse task pages, status lists, and independently scrolling board columns.
- Filter by project, mission, agent, profile, and status; retain preferred filters.
- Track supplied session identities and parent/child relationships.
- Configure profiles, archive history, and enable optional browser notifications.
- Connect Claude and Codex through MCP, with metadata-only reporting.

Install with `npm install -g angine`, then run `angine setup`.

Angine receives agent reports; it does not independently observe all agent actions. Account details are supplied by the user, and session identifiers are recorded only when available. Notifications require an open dashboard tab. This release is intended for local use; shared server deployment and mobile access are future work.
