# Angine v0.1.1

Follow work across Git worktrees and explore it on an interactive graph.

- Git worktrees now share one repository project. Existing projects migrate with a backup while preserving missions, tasks, sessions, archives, old links, and event history. Separate clones remain separate.
- Worktree paths and observed branches are visible in mission and reporter details.
- Each project has a default color inherited by missions and tasks. Edit project colors or set a mission override in its detail page.
- A new Graph tab uses React Flow with top-down connections, compact cards, pan/zoom, a minimap, draggable nodes, and search/filter controls.
- The graph opens with all project cards. Expand projects to see missions and missions to see tasks. New reports update it automatically.
- The README now has clearer setup instructions, a hierarchy example, and feedback guidance.

## Upgrade

```bash
npm install -g angine@latest
angine restart
```

Refresh the dashboard and restart your agent sessions to load updated reporting tools.

Worktree grouping requires Git. Deleted worktrees without a saved repository identity cannot be matched automatically. Angine remains a local app that receives agent reports; it does not independently observe all agent actions. This release does not include a desktop widget or shared server hosting.
