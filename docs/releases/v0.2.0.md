# Angine v0.2.0

Add monitoring checkpoints and Antigravity support to Angine's local agent work dashboard.

- Agents can report request, implementation, deployment, monitoring, and blocker checkpoints through MCP, CLI, or local HTTP. Checkpoints link to a mission or project and do not change task status.
- Monitoring checkpoints appear in a separate highlighted dashboard view, with environment and next-step details when reported.
- `angine setup` now detects Antigravity when its `~/.gemini` folder exists. `angine setup antigravity` configures it explicitly, preserving unrelated MCP entries and instructions. `angine uninstall` removes only Angine-managed settings.
- Add `angine stop` and `angine backup <new-folder-path>` for local server and history management.
- CI covers Ubuntu, macOS, and Windows with Node 20 and 22, and installs the npm archive in an isolated smoke test.

Angine still relies on agents to report their work. It does not independently inspect agent actions or verify deployment health.

## Upgrade

```bash
npm install -g angine@latest
angine restart
```

Restart agent sessions to load updated MCP tools. For Antigravity, refresh its MCP server list after setup.
