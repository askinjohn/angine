# Angine v0.2.1

Fix setup when Antigravity's MCP configuration file exists but is empty.

- Treat an empty `~/.gemini/config/mcp_config.json` as an empty configuration, then preserve a backup before adding Angine settings.
- Report the config path when Antigravity MCP JSON is malformed, making setup errors actionable.

Upgrade with `npm install -g angine@latest`, then run `angine setup` again.
