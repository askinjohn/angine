# Angine v0.3.0

Angine can now send optional native desktop notifications when connected agents report that a task is complete, blocked, or failed.

## Highlights

- Enable system notifications in **Preferences** and choose which agent types can trigger them.
- Notifications come from the local Angine daemon, so the dashboard can be closed while Angine is running.
- Send a test notification from Preferences to check the desktop setup.
- macOS uses system notifications through `osascript`; Linux uses `notify-send`.
- Remove the workspace terminal-launch action. Reported terminal metadata and supported attach actions remain available.

Notifications are opt-in. They depend on the agent reporting task updates to Angine, the daemon running, and desktop notifications being allowed by the operating system.
